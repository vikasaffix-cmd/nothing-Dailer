# Store listing drafts

Play limits: title ≤ 30 characters, short description ≤ 80, full description ≤ 4000. Character counts are checked with `python` and noted next to each item.

## Naming and trademark check

- **App name "NoDialer":** fine. It isn't "Nothing", and "No" is a common word. Don't write it as "N0" or stylise it like Nothing's logo.
- **Never use** in the title, descriptions, screenshots, feature graphic or keywords: "Nothing", "Nothing Phone", "Nothing OS", "Glyph", "CMF", or Nothing's dotted logotype. Don't say "Nothing-style", "Nothing-inspired" or "like Nothing OS". Play's Impersonation and IP policies cover keyword use as well, and Nothing's legal team actively files takedowns.
- **Allowed** description of the style: "dot-matrix", "monochrome", "minimal", "red-accent".
- **Font credit:** "Dot font by Dmitriy Sychiov and Doto, both under the SIL Open Font License 1.1." Don't write "Nothing Font" in the listing. Even though Sychiov named the font that, the name contains the trademark. Fix the in-app string too (readiness fix #6).
- Don't name Truecaller, Google Phone or any carrier (Jio, Airtel) as a comparison. Naming carriers inside the app's voicemail help text is fine.
- **Don't claim** a caller-ID database, "identify every caller", "spam database" or "record both sides". None of these is true without the user's own lookup endpoint or the speaker.

**Full description:**

```
NoDialer replaces your phone app with something calmer: a monochrome, dot-matrix keypad with a single red accent, no ads and no tracking.

Everything stays on your phone. Your contacts, call history, recordings, notes and blocklist never leave it. No account, no analytics.

KEYPAD AND CONTACTS
• Smart keypad search: type 4-8 to find "Gupta", or part of a number
• Favourites row and speed dial on keys 2–9
• Contacts with fast A–Z scrolling
• Dual SIM: choose the SIM per call, or remember a choice
• Home-screen widget with favourites and recent calls

CALLS
• Full-screen incoming call screen that works on the lock screen
• Optional compact "call pill" banner while you use other apps
• Call waiting, hold, swap and merge (conference)
• Speaker, Bluetooth and wired headset picker
• Video calls where your carrier supports them
• Screen turns off when the phone is at your ear
• Adjustable vibration for keys and call events

RECENTS
• Call history grouped by day, with missed, incoming, outgoing and blocked filters
• Search by name or number
• Add a note to any call; it shows up when that person calls again
• Missed-call notifications with Call back and Message

BLOCKING
• Block numbers, hidden callers, or numbers that start with a prefix (for example 140 telemarketing)
• Report spam with one tap; reports stay on your phone
• Optional: connect your own online lookup service for caller names and spam warnings

RECORDING (optional, off by default)
• Turn on automatic call recording, then play, share or delete recordings in the app
• Records through the microphone; on most phones use the speaker to capture both sides
• Recording laws differ by place. You may need the other person's consent.

VOICEMAIL
• Play voicemail audio files from a folder you choose, with call back and share
• Optional on-device transcripts and short summaries (Android 13+); nothing is uploaded
• Help with setting up call forwarding to a voicemail service

LANGUAGES
English, हिन्दी and मराठी, set separately from the phone's language.

To use NoDialer, set it as your default Phone app when asked.

Fonts: dot font by Dmitriy Sychiov and Doto, both under the SIL Open Font License 1.1. NoDialer is an independent app.
```
